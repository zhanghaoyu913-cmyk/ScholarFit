# Roadmap

## v0.1

Goal: story-based questionnaire, transparent rule scoring, and Markdown reports.

Included:

- 8 story chapters
- 80 draft items
- local-first sample scoring
- no required LLM dependency
- ethics and validation documentation

Planned:

- fairness and measurement-invariance checks
- report-language safety tests

Release target:

- theory documentation
- item bank
- scoring code
- sample reports
- privacy policy
- validation report
