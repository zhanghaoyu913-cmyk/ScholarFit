# Item Bank

This directory contains the v0.1 draft story-based item bank.

Each chapter contains 10 items:

- 4 situational judgment items
- 2 ranking items
- 2 slider items
- 1 reflection item
- 1 behavior evidence item

Total v0.1 draft size: 80 items.

All items are draft content. They require expert review, cognitive interviews, pilot testing, reliability analysis, validity evidence, and fairness checks before any strong interpretation.
