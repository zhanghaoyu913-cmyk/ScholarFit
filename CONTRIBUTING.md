# Contributing

ScholarFit is an open psychometric design project, not a casual personality-test repository. Contributions should preserve measurement quality, user safety, and transparency.

## Contribution Areas

- item writing and revision
- construct mapping review
- scoring rule review
- psychometric validation scripts
- fairness and measurement invariance analysis
- privacy-preserving report generation
- bilingual item adaptation

## Item Contribution Checklist

Before adding an item, confirm:

- The item maps to explicit constructs.
- The scenario is realistic for research or doctoral training.
- Options are plausible, not obvious "good vs bad" answers.
- The item avoids clinical diagnosis or protected-class stereotypes.
- The scoring rule explains behavior tendency, not moral worth.
- The item can be reviewed by domain experts and psychometric reviewers.

## Review Expectations

All pull requests that change item banks or scoring should include:

- construct rationale
- expected scoring effects
- potential fairness concerns
- validation data, if available
- before/after sample report snippets when report language changes
